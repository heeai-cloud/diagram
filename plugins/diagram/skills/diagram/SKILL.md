# 희림 다이어그램 — 대지분석 다이어그램

희림 다이어그램 커넥터 도구로 도판(SVG)을 만들고, 사용자와 대화하면서 고친다. 회사판 «사이트 다이어그램 생성기»(diagram.heeai.cloud)와 같은 자료·같은 판을 쓴다. 요청: $ARGUMENTS

**답은 사용자가 이번 요청을 쓴 언어로 한다.** 이 안내문과 도구 메시지가 한국어여도 영어로 물으면 영어로 답한다.

## 1. 연결 확인
- 희림 다이어그램 도구(`find_site`, `create_diagram` …)가 안 보이면 연결부터 안내한다. 커넥터 주소는 `https://diagram.heeai.cloud/mcp`이고, 연결할 때 heeai.cloud 로그인 화면(희림 아이디·비밀번호, 사내 도구 대문과 같은 아이디)이 뜬다. 이미 대문에 로그인된 브라우저면 «연결» 확인 화면만 나온다.
  - Claude Code: `/mcp` → diagram → Authenticate.
  - claude.ai·Cowork: 플러그인의 **커넥터(Connectors)** 탭에서 diagram «연결».
  - ChatGPT 앱(데스크톱): 설정 → 플러그인 → diagram에서 희림 아이디로 로그인한다. 도구는 이 컴퓨터에서 도는 대화(«작업 위치» = «이 컴퓨터»·로컬에서 작업)에만 붙는다. 일반 채팅이나 «클라우드에서 작업»으로 도는 대화라서 도구가 안 보이면, 연결을 다시 하라고 하지 말고 새 대화의 «작업 위치»를 «이 컴퓨터»로 바꿔 다시 부탁하라고 안내한다. Windows용 앱은 로그인한 뒤에도 연결이 안 될 수 있다(앱 쪽 문제).
  - 회사 조직 계정으로 쓰는데 «연결»이 눌리지 않으면 조직 관리자(Owner)가 먼저 **조직 설정 → 커넥터(Organization settings → Connectors)**에서 `https://diagram.heeai.cloud/mcp`를 커스텀 커넥터로 추가해야 한다(플러그인을 넣어도 커넥터는 조직에 저절로 들어가지 않는다).
  - 설치 안내: https://diagram.heeai.cloud/claude/ (희림 아이디로 로그인해서 연다)
- 도구가 «unauthorized»·401로 실패하면 연결이 풀린 것이다(heeai.cloud 비밀번호를 바꿨거나 관리자가 로그아웃시켰거나 연결을 해제한 경우). 같은 방법으로 다시 연결하라고 안내한다.

## 2. 만들기
- 요청이 비어 있으면(`/diagram`만 입력) 무엇을 만들지 고르게 한다.
  - 보기 창이 뜨는 앱(claude.ai 채팅·Cowork): `diagram_home`을 부른다. 장소·반경·도판 종류를 고르는 첫 화면 카드(도판 만들기·상세 표·내 도판)가 뜬다. 사용자가 카드에서 고르면 그 요청이 메시지로 오니 아래 순서대로 만든다. 답은 «아래 카드에서 고르거나 바로 말해 주세요» 한 줄만 쓴다.
  - Claude Code(터미널, 데스크톱 Code 탭): 보기 창이 안 보이므로 도구를 부르지 않고 AskUserQuestion 질문 하나로 고르게 한다. 선택지는 셋이다. 도판 만들기(«명동역 반경 800 m 건축물 용도 도판 만들어 줘»), 상세 표(«명동역 건축물 용도 도판의 용도별 연면적 알려 줘»), 내 도판(«내가 만든 도판 목록 보여 줘»). 도판 만들기나 상세 표를 고르면 장소를 묻는다. 반경·도판 종류를 말하지 않으면 800 m·건축물 용도로 만든다. AskUserQuestion을 쓸 수 없으면 같은 셋을 짧은 목록으로 보여 주고 묻는다.
  - ChatGPT 앱(데스크톱): 보기 창이 뜨지 않고 AskUserQuestion도 없다. 도구를 부르지 않고 Claude Code와 같은 선택지를 번호 목록으로 보여 준 다음 사용자의 답을 기다린다.
  - 어느 쪽인지 모르겠으면 `diagram_home`을 부르고 결과의 `for_claude`를 따른다.
1. `find_site`로 대지를 찾는다. `query`에는 주소·장소 이름만 넣고(반경은 빼고), 그 장소가 어느 나라인지 알면 `country`를 꼭 같이 넣는다 — 한국 `kr`, 두바이 `ae`. 다른 나라 장소여도 그 나라 코드를 넣는다(그리지 못한다는 안내가 온다).
   - 후보가 여럿이면 가장 맞는 것을 고르고, 애매하면 주소 두세 개를 보여 주고 묻는다.
   - 결과에 `available: false`가 있으면 그 `message`를 사용자가 쓰는 언어로 전하고(링크·숫자는 그대로) 멈춘다. 다른 지역 대지로 바꿔 그리거나 우회하지 않는다.
2. 도판 종류가 분명하면 바로 `create_diagram`(diagram_type에 «건축물 용도»·«용도지역»처럼 우리말 이름을 넣어도 된다). 반경을 말했으면 `radius_m`에 미터로 넣는다(«1km» → 1000, 150~1600). 말하지 않았으면 비워 둔다(기본 800 m). 애매하면 `list_diagram_types`로 보고 고른다. 여러 장을 원하면 하나씩 만든다.
   - 두바이는 공식 자료가 없는 판 대신 OpenStreetMap 판(토지이용 현황·랜드마크·문화유산·공공시설)이 나오고, 준공 연대·지적·필지 규모·용도지역은 없다.
   - 처음 보는 장소는 그리는 데 10~60초, 일조·개방감 같은 무거운 도판은 더 걸린다. «오래 걸린다»는 오류가 오면 1~2분 뒤 같은 요청을 한 번 다시 한다.
3. `create_diagram`은 도판(원판)만 낸다 — 제목·범례·출처 줄 없음. 사용자가 말하지 않았으면 이어서 `edit_diagram`으로 제목·범례·출처를 넣지 않는다. 같은 요청에서 «제목·범례도 넣어서»처럼 말했으면 `annotate: true`로 한 번에 만든다(판·위젯이 두 개 생기지 않게).
4. 도판이 바로 보이게 한다.
   - 채팅·Desktop 채팅·Cowork: `create_diagram`·`edit_diagram` 뒤에 대화창 안에 도판 보기 창(그림 + SVG 내려받기·크게 보기 단추)이 뜬다. 그림을 다시 설명하거나 링크를 강조하지 않는다.
   - Claude 데스크톱 **Code 탭**(`mcp__ccd_view__show_pane` 도구가 있는 곳): 이 보기 창이 도구 호출과 함께 접혀서 안 보인다. 그래서 `create_diagram`·`edit_diagram` 뒤마다 바로 ① `get_diagram_file`(`format: "both"`)의 `save_command`를 실행해 작업 폴더에 SVG·PNG를 저장하고 ② `mcp__ccd_view__show_pane`(`pane: "file"`, `path`: 결과의 `show_file` = PNG 파일)으로 채팅 옆 파일 창에 도판을 띄우고 ③ 답 맨 앞에 그 PNG를 마크다운 그림으로 한 줄 넣는다: `![잠실역 반경 500 m · 건축물 높이](heerim_잠실역_height_v1.png)` — 앱이 작업 폴더 그림을 답 안에 바로 그린다. 브라우저 창 `navigate`는 쓰지 않는다(뒤에서만 열려 사용자에게 안 보인다).
   - 터미널 Claude Code: 보기 창도 브라우저 창도 없다. view_url을 주고 4장 «파일»대로 저장한다.
5. 답은 사용자 언어로 짧게: 무슨 도판인지 한 줄, 눈에 띄는 분포 한두 줄, view_url 한 줄(희림 아이디로 로그인한 브라우저에서 열린다). 미리보기 그림을 보고 이상한 점이 있으면 같이 말한다.

## 3. 대화로 고치기
- 사용자의 말을 `edit_diagram`의 `edits`로 옮긴다. 한 번 요청에 여러 수정이면 한 번에 묶어 보낸다.
  - «업무만 파랗게» → `{op:"style", target:"업무", fill:"#2563eb"}`
  - «미상 빼» → `{op:"hide", target:"미상"}` · 다시 보이기 `show`
  - «이 색을 저 색으로» → `{op:"recolor", from:"#…", to:"#…"}`
  - «범례 넣어» → `{op:"legend", position:"right"}` · «제목» → `{op:"title", text:"…", subtitle:"…"}` · «출처 넣어» → `{op:"credit"}`
  - «선 굵게» → `{op:"stroke_scale", factor:1.5}` · «배경 흰색» → `{op:"background", circle:"#ffffff"}`
  - 글자 → `{op:"text", text:"명동역", x:120, y:260}` · 화살표·축척 막대·도형 → `{op:"svg", markup:"<g>…</g>"}`
  - «아까 걸로» → `{op:"revert", version:n}` (혼자 보낸다)
- target 이름은 결과의 `layers` 목록에서 그대로 가져온다. 모르겠으면 `describe_diagram`.
- 좌표: 대지 중심이 (0,0), 1 = 1 m, x는 동쪽, y는 남쪽(SVG). 원 반지름 = 반경(결과의 radius_m). 북쪽 위는 y가 음수.
- 고친 뒤엔 무엇을 바꿨는지 한두 줄 + 새 view_url. 미리보기를 보고 의도와 다르면 바로 한 번 더 고친다.
- 도판의 기본 문법: 원 안에는 글자·이름표·화살표를 두지 않고, 제목·범례·출처는 넣어 달라고 할 때 원 밖에 둔다. 사용자가 원 안에 넣어 달라면 그대로 해 준다. 제목·범례 문구·위치를 바꿔 달라면 `title`·`legend`를 다시 보내면 바뀐다(겹쳐 쌓이지 않는다).

## 3-0. 도판 속 숫자·상세 표
- 도판에 나온 것을 물으면(몇 동인지, 용도별 비율·연면적, 가장 높은 건물, 역·도로 이름 등) 그림을 보고 어림하지 말고 `get_diagram_data`를 부른다. 희림 다이어그램 화면 «상세»·«구성비»와 같은 표다.
  - 합계·평균·개수·조건·상위 N은 `query`로 서버가 계산하게 한다(예: 용도별 연면적 `{group_by:["용도 분류"], values:["연면적"]}`, 20층 이상 `{where:[{column:"지상층", op:">=", value:20}]}`). 표를 직접 더하지 않는다.
  - 표 전체가 필요하면 `page`로 나눠 받거나, 코드를 실행할 수 있을 때만 `whole: true`. 셀이 있으면 결과의 `save_command`로 CSV를 작업 폴더에 저장한다.
  - 결과의 `notes`(세는 기준, «최근 지은 건물 보강» 행은 연면적이 빈칸 등)는 숫자와 함께 짧게 전한다.
  - 합친 도판은 원래 도판마다 부른다. 보기 창 «크게 보기»에는 «CSV 내려받기» 단추도 있다.

## 3-1. 합치기·자유 편집·실시간 링크
- 여러 장 합치기 = `combine_diagrams`(결과는 새 도판, 1판).
  - «겹쳐 줘»(같은 대지의 레이어를 한 장에) → `mode: "overlay"`. 먼저 넣은 판이 맨 아래 — 녹지·용도지역 같은 면 도판을 앞에, 건물·도로를 뒤에. 위에 올리는 판의 바탕 원·회색 건물은 저절로 빠진다. 다른 대지끼리는 안 된다.
  - «나란히 놓아 줘»·«비교»(대지가 달라도 됨) → `mode: "grid"`, 필요하면 `columns`·`captions`·`title`. 칸 이름(캡션)으로 칸을 옮기거나(`transform`) 고칠 수 있다.
- 선·색·글꼴을 더 자세히 → `edit_diagram`의 `attr`(선 끝·이음 모양, 채움 규칙, 글꼴 등)·`transform`(옮기기·돌리기·키우기)을 쓴다.
- 도구로 안 되는 편집(경로 모양을 직접 고치기 등)은 셸이 있을 때만: 저장한 SVG 파일을 직접 고친 뒤 `get_diagram_file` 결과의 `upload_command`를 실행해 다음 판으로 올린다(링크에 바로 반영). 뿌리 `viewBox`는 지킨다.
- 실시간 보기 → 결과의 `live_url`. 사용자의 모든 도판에 같은 주소이고, 가장 최근에 만들거나 고치거나 합친 도판을 3초 안에 따라 보여 준다. 사용자가 «보면서 작업»하고 싶어 하면 한 번만 알려 준다(희림 아이디로 로그인한 브라우저에 열어 두면 된다).

## 4. 파일
- Code 탭: 위 2장 4번대로 SVG·PNG를 저장하고, PNG를 파일 창에 띄우고, 답 맨 앞에 PNG 그림을 넣는다. 답에는 SVG 파일도 마크다운 링크로 적는다(예: `[heerim_잠실역_height_v1.svg](heerim_잠실역_height_v1.svg)`).
- 터미널 Claude Code·Cowork(셸이 있을 때): 만들거나 고칠 때마다 `get_diagram_file`로 받은 `save_command`를 실행해 작업 폴더에 SVG를 저장하고 경로를 알려 준다(같은 도판은 새 판 파일로).
- 저장한 SVG를 사용자가 직접 고쳐 달라고 하면 파일을 고쳐도 되지만, 가능하면 `edit_diagram`으로 고쳐 서버 판 기록과 맞춘다.
- 채팅: `get_diagram_file`의 링크(SVG·PNG)를 준다. SVG는 일러스트레이터·피그마에서 레이어 이름 그대로 열린다.

## 5. 안 될 때
- 결과에 `available: false`가 오면 `message`를 사용자가 쓰는 언어로 전하고 멈춘다(그리지 못하는 지역 등).
- «새로 그리는 도판은 24시간에 …장까지» 오류는 아이디별 하루 한도다. 이미 만든 도판 고치기·합치기·파일 받기는 계속 된다.
- 도구 오류 메시지에 고칠 방법(있는 레이어 이름 등)이 같이 오면 그걸 보고 한 번 다시 시도한다.
